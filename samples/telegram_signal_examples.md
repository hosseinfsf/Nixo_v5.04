# نمونهٔ پیام‌های قابل‌فهم برای Nixo Signal Bridge

این‌ها پیام‌های نمونه‌اند؛ لازم نیست متن کانال دقیقاً همین باشد، اما نام نماد، جهت، حدضرر و حداقل یک هدف باید با وضوح قابل استخراج باشند.

## خرید بازار با سه هدف

```text
BUY XAUUSD NOW
SL: 4040
TP1: 4060
TP2: 4070
TP3: 4080
```

## فروش Limit با محدودهٔ ورود

```text
SELL GOLD LIMIT
ENTRY: 4050-4052
SL: 4060
TP1: 4045
TP2: 4040
```

## اصلاح حدضرر و هدف‌ها

```text
SL: 4052
TP1: 4070
TP2: 4080
```

## انتقال حدضرر به سربه‌سر

```text
SL TO BE
```

## بستن یا لغو

```text
CLOSE TRADE
```

یا برای سفارش معلقی که هنوز فعال نشده:

```text
CANCEL SIGNAL
```

پیام مبهم، سیگنالی که دو جهت مخالف را هم‌زمان اعلام کند، یا پیامی بدون SL/TP به صف معامله نمی‌رود. عکس بدون کپشن متنی فقط در پوشهٔ بازبینی دستی ذخیره می‌شود.

## قالب فشردهٔ Limit/Stop

```text
BUY XAUUSD LIMIT 4060-4062
SL 4050
TP1 4070
```

```text
SELL GOLD STOP 4050
SL 4060
TP1 4040
```
